dashboardv2 構造マップ

Grafana のダッシュボードを Go のコードで作るとき、コードのどこが画面のどこになるのかを、1 つのパネルを例にたどる。画面の概念図・Go のコード・生成される JSON のどれかを選ぶと、ほかの 2 つの対応する部分が強調される。

  1. Go のコード
  2. make generate
  3. JSON ファイル
  4. Grafana が読み込んで表示

画面上で作ったダッシュボードと違い、コードなら変更をレビューでき、同じ規約で何枚でも作れる。
